# 1,000만원 예산 진입 전략: 반려동물 덴탈츄(1안) vs 캡슐형 세탁세제(2안)

## 전제 조건 (대표님 답변 반영)

- **촬영/콘텐츠**: 외주(눈/작가) 활용 가능 — 촬영비는 예산에 반영, 대표님이 직접 촬영하지 않음
- **기존 자산**: 콜레스타 리뷰/고객 리스트는 있지만 이 신상품은 완전 신규 카테고리라 교차판매 불가 — 처음부터 새로 쌓아야 함
- **예산**: 1,000만원은 이 신상품 전용 여유자금 (콜레스타 운영자금과 완전 분리)
- **⚠️ 가리뷰/가구매 관련**: 대표님이 과거 상위노출을 위한 가리뷰·가구매 전략 경험과 성과를 언급하셨으나, 이번 전략에는 포함하지 않았습니다. 전자상거래법·표시광고법 위반이며 마켓(스마트스토어/쿠팡 등) 계정정지·형사처벌 리스크가 있어, 실제 체험단·오픈 리뷰 이벤트 등 합법적 대안으로 대체했습니다.

## 데이터 한계 안내

아래 원가·인증비용 수치 중 상당수는 웹 검색으로 정확한 금액을 확인하지 못해 "확인 필요"로 표시했습니다.
특히 **OEM 소량생산(500~1,000개) 총액**은 카테고리별 실제 견적 없이는 확정할 수 없는 가장 큰 불확실 변수입니다.
아래는 계획 수립을 위한 추정치이며, 실행 전 반드시 최소 2곳 이상 실제 견적을 받아야 합니다.

## 1안: 반려동물 덴탈츄(저작 간식)

### 비용 구조 추정 (1,000만원 배분)

| 항목 | 내용 | 추정 비용 |
|---|---|---|
| 인허가 | 사료 판매업 신고(OEM 위탁 시), 성분등록(정부수수료 5,000원/품목·3일 소요) | 10만원 이하(정부수수료) + 성분분석 시험비 확인 필요(추정 20~50만원) |
| 초기 생산 | 펫원/팩토리펫 등에 500~1,000개 위탁(포장·라벨 포함) | 확인 필요 — 유사 상품 원가 역산 시 개당 2,000~5,000원 추정 → **200~500만원** |
| 패키지/라벨 디자인 | 상세페이지는 기존 render.py 워크플로 재사용 가능, 패키지 라벨만 별도 디자인 | 10~20만원 |
| 상품 촬영(외주) | 프리랜서 사진작가 or 소형 스튜디오 | 25~40만원 |
| 초기 마케팅 | 아래 마케팅 플랜 참고 | 150~250만원 |
| 예비비 | 재고 소진 실패, 견적 오차 대비 | 나머지 (약 150~300만원) |

**합계 추정**: 약 600~900만원 사용, **100~400만원 여유** 확보 가능 (500~1,000개 기준, 생산비 하단 추정 시)

### 타임라인 (주차별)

| 주차 | 할 일 |
|---|---|
| 1주차 | 펫원·팩토리펫 등 2~3곳에 실제 견적 요청(단가/MOQ/리드타임/판매업신고 지원여부 확인), 상품 컨셉·타겟(예: 소형견 치석관리) 확정 |
| 2주차 | 견적 비교 후 OEM 확정, 성분등록 서류 준비 시작, 패키지 디자인 착수 |
| 3~4주차 | 성분등록 진행(3일 소요지만 서류 준비 포함 2주 여유), 초기 생산 발주(리드타임 통상 2~4주 추정) |
| 5~6주차 | 생산 완료 대기 중 상세페이지·상품사진 촬영(외주), 스마트스토어/쿠팡 입점 준비, 체험단 모집 시작 |
| 7~8주차 | 입고, 정식 판매 시작, 오픈 리뷰 이벤트(첫구매 할인+사은품으로 실사용 리뷰 유도), 소액 광고 테스트 시작 |

**첫 매출까지 예상 약 6~8주** — 두 후보 중 상대적으로 빠른 편.

### 마케팅 플랜 (합법적 전략만)

1. **오픈 리뷰 이벤트(진짜)**: 첫 100명 한정 할인가+소용량 사은품 제공 → 실사용 리뷰 확보. 체험단 플랫폼(리뷰노트 등) 이용 시 건당 1.5~2.5만원, 20명 기준 30~50만원.
2. **마이크로 펫 인플루언서 협찬**: 팔로워 1만~5만 계정에 제품 협찬(원고료 없이 제품가치만 제공하는 조건으로 우선 시도), 예산 있으면 원고료형 10~30만원대 소수 진행.
3. **네이버 파워링크 + 쇼핑검색광고**: 일 5,000~10,000원으로 시작, 키워드는 "강아지 덴탈츄", "강아지 치석제거 간식" 등. 2~3개월 소액 테스트 후 성과 좋은 키워드에 집중.
4. **쿠팡 광고**: CPC 100~300원대, 신규셀러 기준 일 1~3만원 정도로 테스트.
5. **콘텐츠**: 외주 촬영본으로 인스타/유튜브 쇼츠에 "실제 강아지가 씹는 영상" 형태 짧은 콘텐츠 반복 게시(반려동물 카테고리는 영상 반응이 좋은 편).

### 리스크 / 확인 필요

- 사료판매업 신고 절차·수수료가 명확히 확인되지 않음 — **관할 시군구청 축산 관련 부서에 직접 문의 필수** (무신고 판매 시 처벌 규정 있음, 2025년 전북 실제 단속 사례 존재).
- "치석제거/관절개선" 등 효능 표현은 근거 없이 쓰면 적발 사례 다수 — 카피 작성 시 반드시 필터링.

## 2안: 캡슐형/시트형 세탁세제

### 비용 구조 추정 (1,000만원 배분)

| 항목 | 내용 | 추정 비용 |
|---|---|---|
| 인허가 | 화학제품안전법상 "안전확인대상생활화학제품" 시험(KTR 등)·신고, **처리기간 40영업일(약 2개월)**, 3년마다 재신고 | 확인 필요 — 성분에 따라 편차 큼, **보수적으로 100~300만원 추정** |
| 초기 생산 | 로드에프 등에 500~1,000팩(30개입 기준) 위탁 | 확인 필요 — 역산 시 팩당 3,000~7,000원 추정 → **300~700만원** |
| 패키지/라벨 디자인 | 상동 | 10~20만원 |
| 상품 촬영(외주) | 상동 | 25~40만원 |
| 초기 마케팅 | 1안과 동일 구조 | 150~250만원 |
| 예비비 | - | 거의 없음 (아래 참고) |

**합계 추정**: 약 900~1,300만원 — **1,000만원 예산을 초과할 위험이 있음** (특히 인증 시험비가 예상보다 높을 경우).

### 타임라인 (주차별)

| 주차 | 할 일 |
|---|---|
| 1주차 | 로드에프·한국오도텍 등에 견적 요청, 제품 처방(성분표) 확정 |
| 2주차 | OEM 확정, KTR 등 시험기관에 시험 견적·성분표 제출 |
| 3~10주차 | **화학제품 시험·신고 진행 (40영업일, 약 2개월)** — 이 기간엔 매출이 발생하지 않음. 동시에 패키지 디자인·상세페이지·체험단 모집은 진행 가능 |
| 11~12주차 | 신고 완료 후 생산 발주(리드타임 2~4주 추정) |
| 13~14주차 | 입고, 정식 판매 시작, 마케팅 본격 집행 |

**첫 매출까지 예상 약 3~3.5개월** — 인증 대기 기간이 길어 자금 회전이 느림.

### 마케팅 플랜

1안과 동일한 구조(오픈 리뷰 이벤트, 인플루언서 협찬, 소액 광고)를 적용하되, "환경 걱정 없는 소용량 캡슐", "가성비" 앵글이 유효(대형사와 정면승부 대신 저가·소용량 틈새 공략).

### 리스크

- **40영업일 시험·신고 기간 동안 현금이 묶임** — 1,000만원 중 상당액이 결과 나올 때까지 회수 불가.
- 시험 비용이 성분에 따라 예상보다 커질 경우 예산 초과 가능성 높음.
- 대형사(LG생활건강, 헨켈 등)와 다이소 PB가 이미 시장을 장악해 가격 경쟁이 치열함.

## 최종 추천

**1안(반려동물 덴탈츄)으로 진입하는 것을 추천합니다.** 이유:
1. 1,000만원 예산 안에서 여유 버퍼를 남기고 실행 가능
2. 인증 절차가 상대적으로 가볍고 빨라 첫 매출까지 절반의 시간
3. 시장이 아직 대형사에 완전히 장악되지 않아 신규 진입 여지가 있음

**단, 실행 전 필수**: 펫원·팩토리펫 실제 견적 확보, 관할 지자체에 판매업 신고 요건 재확인 — 이 두 가지가 확정돼야 1,000만원 예산이 실제로 맞는지 최종 검증됩니다.
